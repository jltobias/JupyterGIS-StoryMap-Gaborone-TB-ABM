# Gaborone TB Agent-Based Modeling Story Maps

This bundle contains three JupyterGIS `.jGIS` story maps designed to accompany notebooks in the Gaborone TB Agent-Based Modeling repository.

## Files

- `content/gaborone_tb_abm_overview_story.jGIS` - model context, spatial heterogeneity, care network, mobility, and model-output storytelling.
- `content/gaborone_tb_intervention_scenarios_story.jGIS` - baseline burden, active case finding, diagnostic delay, cross-border coordination, and scenario comparison.
- `content/gaborone_tb_calibration_validation_story.jGIS` - calibration geography, facility anchors, residuals, and sensitivity analysis.
- `content/data/*.geojson` - small illustrative GeoJSON layers used by the story maps.
- `environment.yml` - JupyterLite xeus environment including `jupytergis-lite`.
- `.github/build-environment.yml` - optional GitHub Pages build environment with `specta` for full-screen story presentation.

## Important note on data

The included spatial layers are deliberately labeled as illustrative placeholders. They are not official ward boundaries, facility registries, or surveillance data. Replace them with GeoJSON generated by the notebooks or approved source data from the repository before public or analytic use.

## Suggested repository placement

Copy this folder structure into a JupyterLite repository or into the existing project:

```text
content/
  *.jGIS
  data/
environment.yml
.github/build-environment.yml
```

The `.jGIS` files reference data paths such as `data/gaborone_tb_neighborhoods.geojson`, matching the `content/` root used by JupyterLite.

## Notebook integration pattern

For each notebook, export model results to GeoJSON with the same file names, or edit the `.jGIS` sources to point to notebook-specific outputs. Good candidate outputs include simulated TB incidence, prevalence, diagnostic delay, care initiation, infectious person-days, and intervention impact by neighborhood or facility catchment.
